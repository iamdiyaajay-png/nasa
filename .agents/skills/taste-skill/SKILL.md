# Taste Skill: Anti-Slop Frontend Engineering & Visual Rigor

This skill enforces premium, bespoke frontend engineering practices that completely eradicate generic AI-generated aesthetics (purple gradients on dark slate, unstyled cards, generic centered hero headings, and missing edge-case pages).

## Core Principles

1. **Anti-Slop Design Mandate**
   - No generic purple/indigo glow on dark slate backgrounds unless specifically mandated by brand identity.
   - No flat, soulless card grids with identical box-shadows.
   - Use high-contrast, intentional palettes, sophisticated neutrals (zinc, neutral, warm stone), and deliberate accent pops.
   - Always implement optical balancing, negative space, and hierarchy that feels handcrafted by senior design engineers.

2. **Bespoke Typography Pairings**
   Never rely on unstyled default browser fonts or raw sans-serif defaults. Choose from intentional pairings:
   - *Technical / SaaS Modern*: Space Grotesk (Headers) + Inter / Geist Sans (Body)
   - *Editorial / High-Trust / Enterprise*: Newsreader / Instrument Serif (Display) + Inter (Body)
   - *Clean Geometric / Consumer*: Plus Jakarta Sans / Cabinet Grotesk (Headers) + Satoshi / Source Sans 3 (Body)
   - *Data-Dense / Telemetry*: JetBrains Mono / Geist Mono (Data/Labels) + Inter (UI Controls)

3. **Spatial System & Grid Discipline**
   - Enforce an 8pt base grid for layout containers and 4pt micro-grid for components, padding, and gaps.
   - Consistent rhythm: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px.
   - Responsive breakpoints: Mobile (375px–640px), Tablet (768px–1024px), Desktop (1280px–1920px).

4. **Tactile Micro-Animations & Interactivity**
   - Micro-interactions on all interactive surfaces (hover, active, focus-visible).
   - Fluid transitions: 150ms–250ms with `cubic-bezier(0.16, 1, 0.3, 1)` or standard ease-out.
   - Active states with subtle scale feedback (`active:scale-[0.98]`).
   - Smooth skeleton pulse animations that match exact layout geometry.

5. **The 34 Production-Grade Pages Integration**
   Every application must account for the complete product lifecycle:
   - **15 Legal Pages**: Privacy Policy (GDPR/DPDP compliant), Terms of Service, Cookie Policy & Active Toggles, Refund, Cancellation, Shipping, Return/Exchange, Disclaimer, Accessibility Statement, DPA, Acceptable Use, Security Policy, Responsible Disclosure, Community Guidelines.
   - **16 Customer Lifecycle Screens**: Login, Register, Email Verification, Forgot Password, Reset Password, Onboarding Stepper, Account & Profile, Billing & Invoices, Upgrade Tier, Downgrade Tier, Cancel Subscription, Payment Success, Payment Failed, Payment Pending, Support Desk, Knowledge Base.
   - **10 UX Resilience States**: 404 Not Found, 403 Forbidden, 500 Internal Error, Maintenance Mode, Offline Mode (PWA Sync), Empty State (with CTA), No Search Results, Skeleton Loading, Error Toasts/Modals, Session Expired (preserving unsaved form state).
